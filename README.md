# أذكاري | أذكار الصباح والمساء

موقع ثابت (Static) لأذكار الصباح والمساء الصحيحة مع مصادرها.

- ملف واحد `index.html` — يعمل مباشرة على GitHub Pages بدون بناء.
- خط Tajawal + Amiri Quran
- مسبحة لكل ذكر، تكبير/تصغير الخط، ثيم غامق/فاتح.

## النشر على GitHub Pages

1. ارفع ملف `index.html` إلى جذر المستودع (branch: `main`).
2. من Settings > Pages اختر:
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)`
3. الرابط سيكون: `https://USERNAME.github.io/REPO/`
